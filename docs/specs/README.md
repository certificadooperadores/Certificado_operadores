# Especificaciones (SDD)

Especificaciones del proyecto, en orden. Cada spec describe **qué** y **por qué**
antes de escribir código.

| Spec | Título | Estado | Rama |
|------|--------|--------|------|
| [NNN](./_plantilla.md) | <!-- título --> | borrador | `feat/...` |

Plantillas:

- [`_plantilla.md`](./_plantilla.md) — especificación.
- [`_plan.md`](./_plan.md) — plan técnico.
- [`_tareas.md`](./_tareas.md) — desglose de tareas.

> Flujo: **spec → plan → tareas → implementación (una función por ciclo:
> implementar → probar → corregir → documentar → commit) → validación.**
